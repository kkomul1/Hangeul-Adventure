# 퍼즐 규칙 명세

퍼즐 규칙의 단일 기준 문서(SSOT). `게임기획초안.md`의 규칙 관련 내용(2~7장)을 대체한다.
규칙 엔진, 솔버, 스테이지 제작은 모두 이 문서를 기준으로 한다.

최종 확정: 2026-07-09

---

## 1. 보드

- 보드는 격자 기반이며 **칸 마스크** 방식으로 정의한다. 각 좌표는 "존재하는 칸" 또는 "없는 칸"이다.
- **없는 칸**은 규칙상 보드 밖과 완전히 동일하다 (아무것도 들어갈 수 없음). 비사각형·이벤트성 보드는 이 마스크만으로 표현한다.
- **빈칸**은 존재하는 칸 중 타일이 없는 칸으로, 이동/분해의 도착지가 될 수 있다.
- MVP 보드 크기: 2x2 ~ **4x4**, 직사각형 허용. 비정형 보드도 검증용으로 1~2개 포함.

## 2. 타일

칸의 상태: **빈칸 / 자음 / 모음 / 글자**. (단어 타일은 없음 — 단어는 목표 진행도 판에서 수집으로 처리, 8장 참조)

- **자음 타일**: 낱자음 14종 + 쌍자음 5종(ㄲㄸㅃㅆㅉ) + 겹받침 11종(ㄳㄵㄶㄺㄻㄼㄽㄾㄿㅀㅄ)
- **모음 타일**: 기본 모음 10종 + 이중모음 11종(ㅐㅒㅔㅖㅘㅙㅚㅝㅞㅟㅢ)
- **글자 타일**: 초성+중성(+종성)이 결합된 완성 글자

모든 한글 자모를 엔진이 지원한다. 스테이지는 필요한 자모만 골라 사용한다.

## 3. 조합의 표준 구조 (canonical)

모든 복합 타일은 **정확히 하나의 표준 조합쌍**을 갖는다. 합성은 표준 쌍으로만 성립하고, 분해는 그 역순으로만 일어난다. (타일이 조합 이력을 기억할 필요 없음 — 구조가 유일하므로 분해는 항상 결정적)

**이중모음** (유니코드 표준 분해와 동일):

| 결과 | 표준 쌍 | 비고 |
|---|---|---|
| ㅐ | ㅏ+ㅣ | |
| ㅒ | ㅑ+ㅣ | |
| ㅔ | ㅓ+ㅣ | |
| ㅖ | ㅕ+ㅣ | |
| ㅘ | ㅗ+ㅏ | |
| ㅙ | ㅗ+ㅐ | ㅘ+ㅣ 불가 |
| ㅚ | ㅗ+ㅣ | |
| ㅝ | ㅜ+ㅓ | |
| ㅞ | ㅜ+ㅔ | ㅝ+ㅣ 불가 |
| ㅟ | ㅜ+ㅣ | |
| ㅢ | ㅡ+ㅣ | |

**쌍자음/겹받침**:

| 결과 | 표준 쌍 | | 결과 | 표준 쌍 |
|---|---|---|---|---|
| ㄲ | ㄱ+ㄱ | | ㄺ | ㄹ+ㄱ |
| ㄸ | ㄷ+ㄷ | | ㄻ | ㄹ+ㅁ |
| ㅃ | ㅂ+ㅂ | | ㄼ | ㄹ+ㅂ |
| ㅆ | ㅅ+ㅅ | | ㄽ | ㄹ+ㅅ |
| ㅉ | ㅈ+ㅈ | | ㄾ | ㄹ+ㅌ |
| ㄳ | ㄱ+ㅅ | | ㄿ | ㄹ+ㅍ |
| ㄵ | ㄴ+ㅈ | | ㅀ | ㄹ+ㅎ |
| ㄶ | ㄴ+ㅎ | | ㅄ | ㅂ+ㅅ |

**글자**: `초성+중성` → 민글자, `민글자+종성` → 받침글자. 종성이 겹받침이면 **겹받침을 먼저 조립한 뒤** 붙여야 한다 (갃 = 가+ㄳ만 가능, 각+ㅅ→갃 불가).

**역할 제약** (글자 합성 시점에 검사):
- 초성 전용: ㄸ, ㅃ, ㅉ (받침 결합 불가)
- 종성 전용: 겹받침 11종 (모음과 초성 결합 불가 — 예: ㄻ+ㅏ 실패)
- 초성/종성 겸용: 낱자음 14종, ㄲ, ㅆ
- 자음+자음은 표준 쌍(위 표)만 합성. 그 외(ㄱ+ㄷ 등)는 전부 실패 — 실제 한글에 없는 조합은 만들지 않는다.

## 4. 합성 규칙 — 공간 배치 기준

합성은 "누가 밀었는가"와 무관하게 **최종 공간 배치**로 판정한다.

| 조합 | 유효 배치 (결합 축) | 예 |
|---|---|---|
| 자음 + 세로형 모음 (ㅏㅑㅓㅕㅣㅐㅒㅔㅖ) | 자음 왼쪽, 모음 오른쪽 (가로) | ㄱ+ㅏ=가, ㅅ+ㅐ=새 |
| 자음 + 가로형 모음 (ㅗㅛㅜㅠㅡ) | 자음 위, 모음 아래 (세로) | ㄱ 위+ㅗ 아래=고 |
| 자음 + 복합형 모음 (ㅘㅙㅚㅝㅞㅟㅢ) | 자음 위 **또는** 자음 왼쪽 (양축) | ㄱ+ㅘ=과 (위에서도, 왼쪽에서도) |
| 모음 + 모음 | 가로, 3장의 표준 쌍만 | ㅗ+ㅏ=ㅘ |
| 자음 + 자음 | 가로, 3장의 표준 쌍만 | ㄹ+ㅁ=ㄻ |
| 민글자 + 자음 (받침) | 글자 위, 자음 아래 (세로) | 가+ㄴ=간 |

**존재하지 않는 합성**: 글자+글자 (단어 타일 없음), 글자+모음 승급 (사+ㅣ≠새), 역순 배치 (ㅏ왼쪽+ㄱ오른쪽), 표준 쌍이 아닌 자모 조합.

## 5. 밀기 — 유일한 보드 조작

타일 T를 방향 d로 한 칸 밀 때 (도착지 C, 그 위 타일 U), 아래 순서로 판정한다:

1. **합성**: C에 U가 있고 T+U가 4장 규칙으로 합성 가능하면 → 합성 (결과는 C에 생성, T 자리는 빈칸)
2. **분해**: d의 축이 T의 **겉조합 축**이면 → 분해. 미는 방향 쪽 성분이 C로 나가고 반대쪽 성분은 제자리에 남는다. 나간 성분은 C에서 재판정: 빈칸이면 안착, 합성 가능하면 **연쇄 합성**, 둘 다 아니면 밀기 전체가 실패
3. **이동**: C가 빈칸이고 T에 d축 방향의 조합이 전혀 없으면 → 한 칸 이동
4. **실패**: 그 외 전부 → 흔들림 연출 + 실패음. **이동 수 증가 없음**

보충 규칙:
- **줄밀기 없음**: 도착지 타일은 절대 밀려나지 않는다 (합성 불가면 실패). 특수 규칙으로 나중에 추가할 수 있게 엔진에 자리만 둔다.
- **연쇄는 1단계로 완결**: 분해로 나간 성분의 합성까지만. (연쇄 합성은 제자리에서 완결되므로 2차 연쇄는 구조적으로 발생하지 않음)
- **분해 vs 이동은 양립 불가**: 분해가 성립하는 축으로는 통째 이동이 불가능하다.

타일별 밀기 결과 정리:

| 타일 | ←→ | ↑↓ |
|---|---|---|
| 낱자모 (ㄱ, ㅏ, ㄲ, ㅘ 등 모든 자음/모음 타일) | 이동/합성/실패 | 이동/합성/실패 |
| 가로 겉조합 (가, 개, ㄲ, ㅘ...) — 단, ㄲ·ㅘ 같은 자모 타일의 겉조합 분해는 아래 참조 | 분해 | 이동/합성/실패 |
| 세로 겉조합 (고, 구...) | 이동/합성/실패 | 분해 |
| 받침글자 — 속에 가로 조합 (간, 갇...) | **잠김 (항상 실패)** | 분해 (↑ 민글자 나감 / ↓ 받침 나감) |
| 받침글자 — 속에 세로 조합 (곤, 굴...) | 이동/합성/실패 | 분해 |
| 복합모음 글자 (과, 귀, 의...) | 분해 (← 자음 / → 모음) | 분해 (↑ 자음 / ↓ 모음) — **통째 이동 완전 불가** |

- 복합 자모 타일(ㄲ, ㄻ, ㅘ, ㅞ 등)도 가로 겉조합 타일로서 ←→ 밀기에 분해된다 (ㅞ→ㅜ+ㅔ, ㅔ→ㅓ+ㅣ 처럼 단계식).
- **각주 (2026-07-09 확정)**: 위 표의 "분해" 서술은 요약이며, 판정 순서 1번(합성)이 항상 우선한다.
  즉 겉조합 축으로 밀더라도 **도착지 타일과 전체 합성이 성립하면 합성**된다.
  예: ㄲ→ㅏ = 까, 고↓ㄴ = 곤, 과↓ㄱ = 곽. (합성이 불성립일 때만 분해 시도)
- 원리 요약: **조합된 축으로 밀면 풀리고, 깨끗한 축으로만 통째로 움직인다. 양축에 조합을 품으면 잠기고, 복합모음 글자는 4방향 모두 분해라 가장 무겁고 가장 유연하다.**

## 6. 분해 세부

- 분해는 표준 구조(3장)의 역순, 겉조합부터 한 단계씩: 간→가+ㄴ, 가→ㄱ+ㅏ, 갃→가+ㄳ, ㄳ→ㄱ+ㅅ, ㅞ→ㅜ+ㅔ, ㅔ→ㅓ+ㅣ
- 미는 방향 쪽 성분이 나간다: 간↑=가가 위로, 간↓=ㄴ이 아래로, 가←=ㄱ이 왼쪽으로, 과→=ㅘ가 오른쪽으로
- 나가는 성분이 도착지에 안착도 합성도 못 하면 분해 자체가 불발 (실패 처리)

## 7. 이동 수와 별

- 이동력(예산) 개념 없음. **이동 수 카운터**가 0부터 증가하며 항상 화면에 표시된다.
- 카운트 대상: 성공한 밀기(이동/합성/분해) **+1**. **수집과 실패한 밀기는 카운트하지 않는다** (2026-07-09 개정 — 수집은 목표 달성 절차이므로 직관상 무료).
- 되돌리기(undo) 시 카운터도 함께 복원. 재시작(R) 시 0으로.
- 실패 상태 없음 — 수 제한이 없으므로 막히면 undo/재시작으로 복구한다.
- **별**: 클리어 시 이동 수가 스테이지별 기준 이하면 별 1~3개.
  - 3별 기준 기본 공식: `최소 수 + max(1, round(최소 수 × 0.1))` (스테이지 데이터로 개별 조정 가능)
  - 1·2별 기준은 스테이지 데이터에 정의
- **루비 별**: 정확히 솔버 검증 **최소 수**로 클리어하면 노란 별 3개가 빨간색+발광 연출로 변한다. 별도의 4번째 별이 아니라 3별의 상위 연출. 도전과제 요소.

## 8. 목표와 수집

- 스테이지 목표 = 요구 타일 목록. 자모 단독, 글자, 또는 단어(글자 슬롯의 나열)일 수 있다. MVP 단어는 **2글자까지**.
- 화면의 **진행도 판**에 목표 슬롯이 표시된다. 미수집 슬롯에도 목표 글자가 흐릿하게 표시되어 무엇을 만들어야 하는지 항상 보인다.
- **수집**: 보드 위 타일이 미수집 슬롯과 **정확히 일치**할 때, 타일 클릭 후 (a) 스페이스바 → 첫 번째 일치 빈 슬롯에 자동 등록, 또는 (b) 진행도 판의 슬롯 클릭 → 해당 슬롯에 등록. 두 방식 모두 지원.
- 수집된 타일은 보드에서 사라진다 (해당 칸은 빈칸이 됨 — 공간을 여는 전략적 수단이기도 하다). 수집은 이동 수에 포함되지 않는다.
- 수집 순서는 무관 ('과'를 '사'보다 먼저 수집 가능). 같은 글자가 여러 슬롯에 필요하면 각각 수집.
- 정확 일치만 허용: '과' 슬롯에 '가'·'광' 불가.
- 수집도 undo 가능 (타일이 원래 칸으로 복귀).
- **클리어**: 모든 슬롯이 채워지는 순간.

## 9. 입력

| 입력 | 동작 |
|---|---|
| 타일 드래그 (마우스) | 드래그 방향으로 1칸 밀기 (길게 끌어도 1회) |
| 타일 클릭 + 방향키/WASD | 해당 방향으로 밀기 |
| 타일 클릭 + Space | 수집 (첫 일치 빈 슬롯) |
| 타일 클릭 + 진행도 판 슬롯 클릭 | 수집 (지정 슬롯) |
| Q 홀드 | 합성 가능한 타일 쌍 하이라이트 |
| E 홀드 | 분해 가능한 타일 하이라이트 |
| Z | 되돌리기 (무제한) |
| R | 스테이지 재시작 |

Q/E 필터는 무료·무제한 (MVP). 합성 결과 미리보기는 없음 ("한글을 처음 배워요" 모드용으로 이후 추가).

## 10. 스테이지 요구사항 (MVP)

- **30개 이상.** 커리큘럼 진행(자모 찾기 → 민글자 → 받침 → 2글자 단어)과 동시에, 아래 **규칙 코너 케이스를 전부 1개 이상의 스테이지에서 검증**해야 한다. 30개로 부족하면 늘린다.
- 모든 스테이지는 솔버로 (1) 풀이 가능성, (2) 최소 수를 검증한 뒤 커밋한다. 루비 별 = 그 최소 수.

코너 케이스 커버리지 체크리스트:
- [ ] 모음 방향성 (가 vs 고, 역순 배치 실패)
- [ ] 받침 형성·분해·재조합 왕복
- [ ] 받침글자의 좌우 잠김을 활용해야 풀리는 배치
- [ ] 이중모음 형성 (표준 쌍), 비표준 쌍 실패 확인 (ㅘ+ㅣ 등)
- [ ] 복합모음 글자의 4방향 분해 / 이동 불가 성질 활용
- [ ] 분해+합성 연쇄 (1단계)
- [ ] 쌍자음 (ㄲ 초성·종성 겸용, ㄸ 받침 불가)
- [ ] 겹받침 조립 (가+ㄳ 경로만 유효) 및 ㄻ 초성 불가
- [ ] 수집 타이밍으로 공간을 열어야 풀리는 배치
- [ ] 같은 글자 2개가 필요한 목표
- [ ] 비정형(비사각형) 보드
- [ ] 루비 별(최적해)과 3별(여유해)이 다른 경로인 스테이지

## 11. MVP 범위 밖 (엔진에 자리만 두는 것)

- 90도 회전, 전체 이동, 전체 회전
- 스테이지별 특수 규칙 플래그 (이동 금지, 분해 금지, 줄밀기 허용, 필터 제한 등) — 엔진은 플래그 구조만 갖고 MVP 스테이지에선 전부 기본값
- 3글자 이상 단어 (엔진은 지원, 스테이지 미사용)
- 위치 지정 목표, 순서 강제 목표
- 큰 맵 탐험 UI (MVP는 리스트형 스테이지 선택), 스토리 연출, 난이도 모드 분기
- 합성 결과 미리보기 필터

## 12. 주요 결정 로그

- 이동/합성/분해를 "밀기" 단일 조작으로 통합, 별도 분해 버튼 없음
- 이동력(예산) 폐기 → 증가형 이동 수 카운터 + 별 기준
- 실패한 밀기는 카운트하지 않음 (UX 우선)
- 단어 타일 폐기 → 수집 방식으로 대체
- 자음끼리 합성해 새 자음을 만드는 규칙(ㄱ+ㄷ=ㄹ 등)은 폐기 유지, 단 실제 한글의 쌍자음·겹받침 조합은 허용
- 조합 경로는 표준 쌍으로 유일화 (ㅝ+ㅣ→ㅞ 불가, 각+ㅅ→갃 불가)
- 자음+복합모음은 양축(위/왼쪽) 결합 — 결과적으로 복합모음 글자는 통째 이동 불가
- 줄밀기 금지, 연쇄는 1단계
