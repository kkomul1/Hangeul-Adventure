# 스토리 기획 (뼈대 v1)

2026-07-09 사용자 구술 기반. 구현 전 기준 문서.

## 1. 세계관과 목표

- **가나다 대마왕**이 훈민정음을 빼돌려 산산조각 낸 뒤 파편을 각 지역에 흩뿌렸다.
- 자음 중 **ㄱ, ㄴ, ㄷ과 모음들만** 세상에 남기고, 나머지 자음이 들어간 글자들을 세상에서 사라지게 만들었다.
- 게임의 목표: **자음들을 되찾고 훈민정음을 복원**하는 것. 최종장에서 가나다 대마왕과 전투.

## 2. 깨진 글자 시스템 (핵심 연출)

- 아직 되찾지 못한 자음이 포함된 글자는 **깨진 형태**로 표시된다 (물음표 문자가 아니라 "깨진 듯한" 시각 효과 — 글리치/균열/먹 번짐 등).
- 예: 타이틀 "한글 어드벤처"는 최초 실행 시 온전히 보이다가, 게임 시작(대마왕의 습격) 후에는
  ㅎ·ㅇ·ㅊ·ㅂ이 미회수 상태이므로 "?글 ?드??" 식으로 깨져 보인다 (ㄱ,ㄷ 포함 글자만 온전).
- 적용 범위: 타이틀, 맵 간판/라벨, UI 텍스트 일부 — 자음을 되찾을수록 세상의 글자가 점점 복원된다.
- 판정 규칙(안): 글자의 초성·종성에 미회수 자음이 하나라도 있으면 깨짐. 모음은 항상 온전.

## 3. 자음 회수와 훈민정음 파편

- **자음 회수**: 방(지역/구역)을 클리어할 때마다 자음 1개씩 회수.
- **훈민정음 파편** 획득 경로 (복수 채널):
  1. 방 여러 개 클리어 보상
  2. 맵 탐험: 특정 위치 도달/특정 행동 수행 시 발견
  3. **맵 자체가 거대한 퍼즐**: 단계 클리어 → 맵 요소가 움직임/변형 → 맵의 거대 퍼즐을 풀면 파편 획득
  4. 상점에서 고가 판매
- **엔딩**: 파편을 모두 모아 훈민정음 복원 → 가나다 대마왕과 최종 전투.
- **정합성 제약**: 훈민정음 복원 완료 시점에 자음이 전부 회수된 상태여야 함 —
  파편 획득 조건을 자음 진행에 종속시키는 설계 필요 (예: 마지막 파편은 최종 지역 = 마지막 자음 지역에 위치).

## 4. 전투 시스템 (초안 — 사용자 기획, 변경 여지 있음)

- 행동: **공격 / 수비 / 기술**(=스킬)
- 대미지: (나의 공격력 또는 기술 공격력) − (상대 방어력)
- 수비: 다음에 받을 대미지 경감
- **몬스터의 반격 구조**: 내가 행동하면 몬스터가 간단한 한글 퍼즐을 제시.
  - 특정 이동 수 안에 풀지 못하면(초과할수록) 몬스터의 공격이 강해지거나 잦아짐
  - 제한 내 성공 시 **카운터 펀치** 기회
- 장비(무기=공격력, 방어구=방어력)가 여기서 실수치로 작동 — 상점/골드 루프의 사용처.
- **전조 시스템** (2026-07-09 합의): 몬스터의 다음 퍼즐 공격의 수준(난도/제한 수/속성)을 미리 보여줘서
  수비를 전략적으로 선택할 수 있게 한다. 수비 = 다음 퍼즐에 유리한 변형 (예: 제한 수 +2).
- 최종 보스전 아이디어(제안): 가나다 대마왕의 공격 = 보드의 타일을 깨뜨리거나 지움 →
  회수한 자음이 많을수록 대응 수단이 많아지는 구조로 스토리와 전투를 연결.

## 4.5 사천왕 구조 (2026-07-09 추가 — 포켓몬 관장 모델)

- 가나다 대마왕의 부하 **사천왕** 4명이 각 지역의 주인: 지역 테마의 전문가이자 최종 시험.
  (예: 받침 고개의 받침 사범, 자모 사찰의 겹자모 노승, 낱말 저잣거리의 낱말 장사꾼, 미궁의 넷째)
- 격파 보상: 자음 회수 + **증표(배지)** 수집 진열 + 훈민정음 파편 경로 연결.
- 모험 요소 후보: 글자 도감(만든 글자 전부 기록 — 최우선 후보), NPC 심부름 퀘스트, 숨겨진 보물, 사천왕 재대결.
- 이미지 스타일 A/B 예정: 수묵 담채 vs 고해상 도트풍(JRPG 보스 초상) — 사용자 판정 대기.

## 5. 미결정 사항

- 대마왕 부하(지역 보스)들의 컨셉·이름
- "방" 단위의 정의 (현 스테이지 묶음? 새 구역 개념?)
- 깨진 글자의 시각 표현 방식 (셰이더 vs 대체 글리프 vs 스프라이트 오버레이)
- 전투 밸런스 수치 전반, 기술(스킬) 목록
- 초안(게임기획초안.md)의 "14자음/각 장 1자음" 구조와 현 월드(지역 4~5개)의 정합 — 지역보다 자음이 많음
