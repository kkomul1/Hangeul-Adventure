# 스테이지 풀이노트 (7~50)

스테이지 7~50의 설계 의도와 검증된 풀이 경로. 솔버 검증 실패 시 이 문서의 경로와 대조할 것.

- 검증 도구: `Tools/Solver/solver.cs` (BFS, 퍼즐규칙명세.md 기준 구현)
  - 빌드: `C:\Windows\Microsoft.NET\Framework64\v4.0.30319\csc.exe -nologo -codepage:65001 -out:solver.exe Tools\Solver\solver.cs`
  - 실행: `solver.exe stage_007.json ...` (풀이 가능성 + 최소 수 + 최적 경로 출력)
  - 정합성 근거: 기존 스테이지 1~6의 minMoves(2, 3, 3, 4, 6, 4)를 정확히 재현함.
- 좌표는 (행, 열), 0부터. 방향은 미는 방향.
- **계수 기준 변경 (2026-07-09 개정)**: 수집은 이동 수에 포함되지 않는다. 솔버도 0-1 BFS로 수정되어 수집을 0수로 계산한다 (스테이지 1=1수, 6=3수로 정합 확인). **7~50 절과 하단 요약표의 "최소 수"는 구기준(수집 +1 포함) 수치**이며, 각 스테이지의 minMoves(파일 값)가 신기준 수치다. 51~54 절부터는 신기준으로 기록.
- 솔버 버그 수정 (2026-07-09): 표준 쌍 테이블에 ㅄ(ㅂ+ㅅ) 누락 → 추가. 엔진(Hangul.cs)에는 원래 있었으므로 게임 동작에는 영향 없음. ㅄ이 필요한 스테이지는 51이 처음.
- 모든 경로는 솔버가 찾은 최적해 그대로임 (손 풀이 아님).

## 7~10 민글자 심화

### 7. 길을 비켜라 — 목표 노 (최소 4)
- 가르침: 방해 타일을 옆으로 치워 세로 합성 길 열기.
- 함정: ㅁ을 ㅗ에 밀면 '모'가 되어 ㅗ를 잃음 (undo 학습).
- 경로: ㅁ(1,0)→오른쪽 이동 / ㄴ(0,0)→아래 / ㄴ(1,0)→아래 합성 노 / 수집.

### 8. 위아래 바꾸기 — 목표 무 (최소 6)
- 가르침: 세로 순서 교환 (스테이지 4의 세로판). 폭 1이면 못 지나가므로 옆 칸 활용.
- 경로: ㅜ→오른쪽 / ㅜ→아래 / ㅁ→위 / ㅁ→오른쪽 / ㅁ→아래 합성 무 / 수집.

### 9. 엉뚱한 짝 — 목표 이 (최소 4)
- 가르침: 눈앞의 모음(ㅏ)이 정답이 아닐 수 있음. ㅇ+ㅏ=아는 오답 우회로.
- 경로: ㅇ→아래 / ㅇ→오른쪽 / ㅇ→오른쪽 합성 이 / 수집.

### 10. 무가 아니라 두 — 목표 두 (최소 4)
- 가르침: 벽(#) 있는 보드 + 함정 합성. ㅜ를 위로 밀면 ㅁ와 합쳐져 '무'(오답).
- 경로: ㅁ(1,1)→왼쪽 / ㄷ→아래 / ㄷ→아래 합성 두 / 수집.

## 11~15 받침

### 11. 세 조각 — 목표 손 (최소 7)
- 가르침: 세 조각으로 받침글자 조립. 조립 위치 선정(맨 아랫줄에서 만들면 ㄴ을 못 붙임).
- 경로: ㄴ(0,2)→아래 / ㅗ(2,0)→위 / ㅗ(1,0)→위 합성 소(ㅗ를 ㅅ쪽으로 밀어도 합성됨) / 소→오른쪽 ×2 / 소→아래 합성 손 / 수집.

### 12. 받침 갈아끼우기 — 목표 간 (최소 5)
- 가르침: 받침 분해(각↓=ㄱ이 아래로) 후 다른 받침 부착. 받침글자 좌우 잠김 체감(각은 좌우로 안 밀림).
- 경로: 각↓ 분해(가/ㄱ) / ㄱ→오른쪽 / 가→아래 / 가→아래 합성 간 / 수집.

### 13. 물길 내기 — 목표 물 (최소 6)
- 가르침: 민글자를 만들어 받침 위로 나르기 (무→물 연속 합성).
- 경로: ㄹ→왼쪽 / ㄹ→아래 / ㅜ→위 합성 무(모음을 자음 쪽으로 밀어도 됨) / 무→오른쪽 / 무→아래 합성 물 / 수집.

### 14. 재활용 — 목표 금 (최소 6)
- 가르침: 완성 글자(김)를 두 단계 분해해 부품(ㄱ, ㅁ) 수확. ㅣ는 버리는 부품.
- 경로: 김↑ 분해(기 위로, ㅁ 잔류) / 기← 분해(ㄱ 왼쪽으로, ㅣ 잔류) / ㅡ↑ 합성 그 / ㅁ→왼쪽 / 그↓ 합성 금 / 수집.

### 15. 빌려 쓰기 — 목표 만 (최소 5)
- 가르침: 좌우로 잠긴 받침글자(간)에서 부품만 빼내 쓰기. 간은 절대 좌우로 안 밀리고 세로 분해만 됨.
- 경로: ㅁ→오른쪽 합성 마 / 간↑ 분해(가 위로, ㄴ 잔류) / ㄴ→오른쪽 / 마↓ 합성 만 / 수집. (가는 벽으로 남음)

## 16~19 분해 필수

### 16. 다시 조립 — 목표 소 (최소 5)
- 가르침: 잘못 조합된 글자(수)는 풀어야만 답이 나옴. 분해 방향 = 나가는 성분.
- 경로: 수↓ 분해(ㅜ 아래로) / ㅜ→오른쪽 / ㅅ→아래 / ㅅ→아래 합성 소 / 수집.

### 17. 연쇄 반응 — 목표 곤 + 고 (최소 4)
- 가르침: 분해+합성 연쇄(1단계). 곡을 ㅗ 위에서 아래로 밀면 ㄱ이 나가며 ㅗ와 즉시 합성 → 고가 2개 생김.
- 경로: 곡↓ 분해+연쇄합성(고/고) / 수집 고 / 고↓ 합성 곤(ㄴ이 바로 아래에 대기) / 수집 곤.

### 18. 짝 바꾸기 — 목표 오 + 니 (최소 9)
- 가르침: 두 글자를 모두 해체해 짝을 교차 재조합 (노+이 → 오+니).
- 경로: 노→오른쪽 이동 / 노↓ 분해(ㅗ 아래로) / ㅗ↓ / 이← 분해(ㅇ 왼쪽으로) / ㅇ↓ 합성 오 / 수집 오 / ㄴ↓ / ㄴ→오른쪽 합성 니 / 수집 니.

### 19. 밥 짓기 — 목표 밥 (최소 6)
- 가르침: 받침 수확 + 글자를 "분해했다 재조립"하며 옆 칸으로 옮기기 (민글자는 좌우로 통째 이동 불가하므로).
- 함정: 바를 아래 ㄱ에 밀면 박으로 되돌아감.
- 경로: 박↓ 분해(ㄱ 아래로) / ㅂ↓ / 바→오른쪽 분해(ㅏ만 오른쪽으로) / ㅂ→오른쪽 합성 바(한 칸 옆에 재조립) / 바↓ 합성 밥 / 수집.

## 20~23 이중모음·복합모음

### 20. 두 모음 — 목표 와 (최소 3)
- 가르침: ㅘ = ㅗ+ㅏ 표준 쌍(가로). 모음부터 만들어야 함 — ㅇ+ㅗ=오를 먼저 만들면 오+ㅏ는 불가(글자+모음 승급 없음).
- 경로: ㅏ← 합성 ㅘ / ㅇ↓ 합성 와 / 수집.

### 21. 초성 갈아타기 — 목표 화 (최소 5)
- 가르침: 복합모음 글자(과)의 4방향 분해. 왼쪽으로 밀면 ㄱ이 나가고 ㅘ가 남음. ㅘ는 세로로는 통째 이동 가능.
- 경로: 과← 분해(ㄱ 왼쪽으로) / ㅘ↓ 이동 / ㅎ← / ㅎ↓ 합성 화 / 수집.

### 22. 쥐 잡기 — 목표 쥐 (최소 4)
- 가르침: ㅟ = ㅜ+ㅣ 표준 쌍. 함정: ㅈ+ㅣ=지, ㅈ+ㅜ=주 (오답 합성 가능).
- 경로: ㅣ↓ / ㅣ← 합성 ㅟ / ㅈ↓ 합성 쥐 / 수집.

### 23. 움직이지 않는 글자 — 목표 완 (최소 7)
- 가르침: 복합모음 글자(와)는 통째 이동 완전 불가 → 만든 자리에서 받침을 데려와야 함. 단 합성 판정은 분해보다 우선이라 와를 ㄴ 쪽으로 밀면 완이 됨.
- 경로: ㅇ→오른쪽 / ㄴ↓ / ㅗ→오른쪽 합성 ㅘ / ㅘ↑ 합성 와 / ㄴ← / 와↓ 합성 완 / 수집.

## 24~26 쌍자음·겹받침

### 24. 쌍둥이 ㄱ — 목표 꼬 (최소 5)
- 가르침: ㄲ = ㄱ+ㄱ(가로). ㄲ은 가로 조합 타일이라 세로로만 통째 이동.
- 경로: ㄱ(0,2)← / ㄱ(0,1)← 합성 ㄲ / ㄲ↓ 이동 / ㄲ↓ 합성 꼬 / 수집.

### 25. 있다! — 목표 있 (최소 4)
- 가르침: ㅆ은 받침 가능(초성/종성 겸용). 글자와 쌍자음을 각각 만들어 결합.
- 경로: ㅇ→오른쪽 합성 이 / ㅅ→오른쪽 합성 ㅆ / 이↓ 합성 있 / 수집.

### 26. 삶 — 목표 삶 (최소 4)
- 가르침: 겹받침은 조립된 것만 받침이 됨. ㄹ+ㅁ=ㄻ을 먼저 만들고 사+ㄻ=삶. 함정: 사+ㄹ=살을 먼저 만들면 살+ㅁ은 불가(겹받침 조립 경로 위반) → undo.
- 경로: ㅅ→오른쪽 합성 사 / ㄹ→오른쪽 합성 ㄻ / 사↓ 합성 삶 / 수집.

## 27~32 단어·종합

### 27. 나무 — 목표 단어 나무 (최소 4)
- 가르침: 첫 2글자 단어. 글자마다 만들어 수집.
- 경로: ㄴ→오른쪽 합성 나 / 수집 나 / ㅁ↓ 합성 무 / 수집 무.

### 28. 오이 밭 — 목표 단어 오이 (최소 6)
- 가르침: 수집 타이밍으로 공간 열기. 2x2 꽉 찬 보드 — 이를 먼저 만들어 수집해야 오를 만들 자리가 생김 (수집 전에는 ㅇ이 ㅗ 위로 갈 수 없음).
- 경로: ㅇ(1,0)→오른쪽 합성 이 / 수집 이 / ㅗ↓ / ㅇ→오른쪽 / ㅇ↓ 합성 오 / 수집 오.

### 29. 바다 — 목표 단어 바다 (최소 5)
- 가르침: 비정형(#) 보드 + 같은 모음(ㅏ) 2개를 각각 다른 자음에 배분.
- 경로: ㅂ→오른쪽 합성 바 / 수집 바 / ㄷ→오른쪽 / ㄷ→오른쪽 합성 다 / 수집 다.

### 30. 구름 — 목표 단어 구름 (최소 11)
- 가르침: 4x4 종합 — 세로 합성 2회 + 받침 + 흩어진 부품의 동선 계획.
- 경로: ㄱ↓ / ㅁ(0,3)↓ / ㄱ↓ 합성 구 / 수집 구 / ㅁ↓ / ㅡ→오른쪽 / ㅡ↑ / ㅡ↑ 합성 르 / 르→오른쪽 / 르↓ 합성 름 / 수집 름.

### 31. 뽀뽀 — 목표 단어 뽀뽀 (최소 6)
- 가르침: 같은 글자 2개 목표. ㅃ=ㅂ+ㅂ을 두 번 조립. 왼쪽으로 밀어 ㅃ을 ㅗ 바로 위에 만들면 최단.
- 경로: ㅂ(0,1)← 합성 ㅃ / ㅃ↓ 합성 뽀 / 수집 / ㅂ(2,1)← 합성 ㅃ / ㅃ↓ 합성 뽀 / 수집.

### 32. 과일 — 목표 단어 과일 (최소 7)
- 가르침: 피날레 — 복합모음 글자 + 받침 + 비정형 4x4. 과는 만든 즉시 수집(이동 불가이므로).
- 경로: ㅏ← 합성 ㅘ / ㄱ→오른쪽 합성 과 / 수집 과 / ㅇ→오른쪽 / ㅇ→오른쪽 합성 이 / 이↓ 합성 일 / 수집 일.

## 33~37 단어 다양화

### 33. 사자 — 목표 단어 사자 (최소 8)
- 가르침: 같은 모음(ㅏ) 2개를 두 자음에 배분. 자음이 모음의 왼쪽까지 돌아가는 동선.
- 경로: ㅅ→오른쪽 / ㅅ→오른쪽 합성 사 / 수집 사 / ㅈ← / ㅏ(2,0)→오른쪽 / ㅈ↓ / ㅈ→오른쪽 합성 자 / 수집 자.

### 34. 두부 — 목표 단어 두부 (최소 6)
- 가르침: 세로 합성 2열 병렬 처리.
- 경로: ㄷ↓ / ㅂ↓ / ㄷ↓ 합성 두 / 수집 / ㅂ↓ 합성 부 / 수집.

### 35. 오리 — 목표 단어 오리 (최소 7)
- 가르침: 비정형 보드에서 세로(오)+가로(리) 합성 혼합.
- 경로: ㅗ↓ / ㅇ→오른쪽 / ㅇ↓ 합성 오 / 수집 / ㄹ→오른쪽 / ㄹ→오른쪽 합성 리 / 수집.

### 36. 김밥 — 목표 단어 김밥 (최소 9)
- 가르침: 받침 2개 단어. 함정: ㅂ+ㅂ=ㅃ을 만들면 안 됨(밥에는 ㅂ이 초성·종성으로 따로 필요).
- 경로: ㅣ← 합성 기 / 기↓ 합성 김 / 수집 김 / ㅂ(2,1)← / ㅏ↑ / ㅂ→오른쪽 합성 바 / ㅂ(3,2)← / 바↓ 합성 밥 / 수집 밥.

### 37. 눈물 — 목표 단어 눈물 (최소 10)
- 가르침: 4x4에서 받침글자 2개 조립. 같은 자모(ㄴ 2개, ㅜ 2개) 배분 + 긴 동선 계획.
- 경로: ㄴ↓ 합성 누 / ㄹ↓ ×2 / ㅜ↑ 합성 무 / 무→오른쪽 / 무↓ 합성 물 / 수집 물 / ㄴ(3,0)↑ / 누↓ 합성 눈 / 수집 눈.

## 38~41 함정 규칙 (ㄸ 받침 불가 · 비표준 쌍)

### 38. 곧 간다 — 목표 곧 (최소 5)
- 가르침: **ㄸ 받침 불가 함정.** ㄷ이 2개 있어 ㄷ+ㄷ=ㄸ을 만들 수 있지만, 고+ㄸ은 실패(ㄸ은 초성 전용) — ㄷ 하나만 받침으로 써야 함.
- 경로: ㄱ↓ / ㅗ↑ 합성 고 / 고← 이동 / 고↓ 합성 곧 / 수집.

### 39. 딸기 — 목표 단어 딸기 (최소 7)
- 가르침: 38의 반전 — ㄸ은 **초성으로는** 가능. ㄸ→따→딸 연속 합성.
- 경로: ㄷ→오른쪽 합성 ㄸ / ㄸ→오른쪽 합성 따 / 따↓ 합성 딸 / 수집 딸 / ㄱ→오른쪽 / ㄱ→오른쪽 합성 기 / 수집 기.

### 40. 왜? — 목표 왜 (최소 5)
- 가르침: **비표준 쌍 함정.** ㅗ+ㅏ=ㅘ를 먼저 만들면 ㅘ+ㅣ는 불가 — ㅏ+ㅣ=ㅐ를 먼저 만들고 ㅗ+ㅐ=ㅙ 순서여야 함. (ㅘ를 ㅣ 쪽으로 밀면 분해+연쇄로 ㅐ가 생겨 복구 가능 — 발견 요소)
- 경로: ㅣ← 합성 ㅐ / ㅗ→오른쪽 합성 ㅙ / ㅙ↓ 이동 / ㅇ→오른쪽 합성 왜 / 수집.

### 41. 과자 — 목표 단어 과자 (최소 6)
- 가르침: ㅏ 2개 중 어느 것을 ㅘ에 쓸지 배분. 과는 만든 즉시 수집(이동 불가).

## 51~54 최고 난이도 실험 (신기준: 수집 0수)

난이도 체감 판단용 실험 스테이지. `"difficulty"` 필드(4~7)가 추가됐고 minMoves는 0(미확정), stars는 [0,0,0]으로 둔다. 난이도의 원천은 수가 많음이 아니라 **수읽기 깊이**다.

**함정 가지 판정 기준**: 이 규칙 체계는 모든 합성이 분해로 역연산 가능해 "절대적 풀이 불가" 상태가 구조적으로 거의 만들어지지 않는다 (함정 상태 14종을 솔버로 전수 검증한 결과 전부 복구 가능). 따라서 함정은 **재시작 우위**(그 상태에서의 잔여 최소 수 ≥ 처음부터의 최소 수 — 즉 지금까지의 수가 전부 헛수고인 상태)로 정의하고, 모든 함정을 "함정 상태를 스테이지로 만들어 솔버 실행"하는 방식으로 정량 검증했다.

### 51. 값 — 목표 값 (최소 10, difficulty 5)
- 시험: 겹받침 조립 순서 강제(ㅄ 선조립) + **조합 위치의 열(column) 커밋** + ㅄ 걸음 기술.
- 구조: 1행이 (1,3) 하나만 뚫려 있어, 가는 반드시 (0,3)에서 만들어 3열로만 내려갈 수 있다. ㅄ은 가로 잠김(세로 이동만 가능)이라 반드시 3열 위 (2,3)에서 완성해야 한다. 최적해는 ㅄ을 (2,2)에서 만든 뒤 **오른쪽으로 분해→재합성**해 한 칸 옮기는 기술(스테이지 19의 심화)을 쓴다. ㅅ을 (2,2)→(2,3)으로 먼저 보내고 ㅂ이 뒤따라 합성하는 동순 경로도 같은 10수.
- 경로: ㄱ→×2 / ㄱ→ 합성 가(0,3) / 가↓ / ㅂ→ / ㅅ↑ / ㅂ→ 합성 ㅄ(2,2) / ㅄ→ 분해 / ㅂ→ 재합성 ㅄ(2,3) / 가↓ 합성 값 / 수집.
- 함정 (솔버 검증):
  - 가를 0열에서 조기 합성(ㅏ를 왼쪽으로 밀기, 3수): 잔여 13 > 10 → **재시작 우위**. 1열도 잔여 11 > 10 → **재시작 우위**. (아래가 전부 #라 분해로만 복구)
  - 가+ㅂ=갑 (8수 시점): 잔여 8, 총 16수 (+6 손해).
  - ㅄ을 (3,2)에서 조기 합성 / 가+ㅅ=갓: 각각 +1, +2 손해.

### 52. 기와 — 목표 기와 (최소 12, difficulty 6)
- 시험: 3x3 밀집 보드에서 **수집으로만 열리는 통로** + 오답 합성 유혹 3종.
- 구조: ㅏ가 ㅘ 자리(0열 상단)까지 가는 유일한 통로가 2열 세로줄→(0,2)인데, (0,2)는 기를 만들어 **수집해야만** 비워진다. 그 전에 ㅣ를 2열에서 위로 빼돌려 기를 만드는 순서가 선행돼야 한다. 8칸 중 5칸이 타일이라 한 수 한 수가 통로를 막는다.
- 경로: ㄱ← / ㅣ↑×2 / ㄱ→ 합성 기 / 수집 기 / ㅗ→(0,1) / ㅇ↑×2 (0,0) / ㅏ→(2,2),↑(1,2),↑(0,2) / ㅏ← 합성 ㅘ(0,1) / ㅇ→ 합성 와 / 수집 와.
- 함정 (솔버 검증):
  - **ㅇ+ㅣ=이 (3수)**: 잔여 22 ≫ 12 → **사실상 데드락** (복구가 새로 푸는 것의 2배 가까이 든다. 밀집 보드라 분해 복구 동선이 극도로 꼬임).
  - ㅏ+ㅣ=ㅐ (첫수 유혹, 인접 배치): 잔여 13 > 12 → **재시작 우위**.
  - ㅇ+ㅏ=아: +1 손해 (가벼운 undo 학습용).

### 53. 새우 — 목표 새우 (최소 12, difficulty 6)
- 시험: **분해+연쇄 합성이 최적해의 열쇠** + 수집 게이트 + 방해 타일 관리.
- 구조: 첫수 "사→오른쪽"이 분해+연쇄(ㅏ가 ㅣ와 즉시 ㅐ 합성)로 2수 만에 새를 완성하는 유일한 지름길. 새를 수집해야 0행이 비어 ㅇ이 (0,3)→(1,3) 유일 통로로 내려갈 수 있다 (1행이 그 외 전부 #). 2행의 방해 ㅣ는 우 조립 지점 (2,1) 위를 지나므로 왼쪽 구석 (2,0)까지 밀어내야 한다.
- 경로: 사→ 분해+연쇄(ㅅ,ㅐ) / ㅅ→ 합성 새 / 수집 새 / ㅇ→×3,↓×2 / ㅣ←×2 / ㅇ←×2 / ㅇ↓ 합성 우 / 수집 우.
- 함정 (솔버 검증):
  - ㅣ를 먼저 (0,3)으로 대피(비연쇄 유도, 1수): 잔여 13 > 12 → **재시작 우위** (연쇄 없이 풀면 3수 손해).
  - ㅜ를 위로 조기 이동 (1수): 잔여 13 > 12 → **재시작 우위** ((2,1)에 ㅜ가 오면 ㅇ이 위에 설 자리가 #뿐).
  - 방해 ㅣ를 오른쪽 (2,3)으로 밀기: 잔여 12 = 12 → 재시작 동률 (그 수가 무효).

### 54. 여왕 — 목표 여왕 (최소 11, difficulty 7)
- 시험: **합성이 분해보다 우선한다는 각주 규칙이 마지막 수** + 복합모음 글자(와)의 이동 불가 배치 계획 + ㅇ 3개 배분.
- 구조: 와는 만들면 절대 움직일 수 없으므로, 종성 ㅇ이 들어갈 빈칸이 아래에 확보되는 (2,1)에서 만들어야 한다. 마지막 수 "와↓"는 분해될 것 같지만 아래 ㅇ과 **합성이 우선**되어 왕이 된다 (겉보기 모순 수). ㅘ를 (3,1)에서 만든 뒤 위의 ㅇ 쪽으로 밀어 올려 와를 완성하는 순서도 비직관적.
- 경로: ㅇ(0,0)→ / ㅇ→ 합성 여 / 수집 여 / ㅇ(1,3)↓,←×2 (2,1) 대기 / ㅏ→ / ㅗ↓ / ㅗ→ 합성 ㅘ(3,1) / ㅘ↑ 합성 와(2,1) / ㅇ(3,2)← / 와↓ 합성 왕 / 수집 왕.
- 함정 (솔버 검증):
  - **ㅇ+ㅏ=아 (6수 시점)**: 잔여 14 > 11 → **재시작 우위** (총 20수, +9. ㅏ는 ㅘ의 유일 재료인데 아는 3행에서 만들어져 복구 동선이 김).
  - ㅇ+ㅗ=오 (2수): 잔여 13 > 11 → **재시작 우위** (오+ㅏ 승급은 없으므로 와가 안 됨 — 스테이지 20의 교훈을 최고 난도에서 재시험).
  - 와를 (3,1)에서 완성: 잔여 6 (+2 손해. 종성 자리가 없어 위로 분해 후 재조립).
