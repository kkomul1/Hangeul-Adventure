# 스토리 기획 (뼈대 v2 — 묵음 대왕 세계관)

2026-07-09 사용자 구술 기반 v1 → **2026-07-17 개편 확정 반영 v2**. 구현 전 기준 문서.
개편 내역과 사유는 말미 12장 "개정 이력" 참조. v1과 충돌하면 이 문서가 우선한다.

관련 문서: `게임기획초안` 13·14·15·16장(맵·스토리·자음 구조·엔딩), `구현결정로그` D-22(자음 게이트)·D-23(방 보상),
`사이드뷰 전환 기획` 7장(맵별 지형), `아트 디렉션 v2` 4·5장(맵 컨셉·에셋 수량).

## 1. 세계관과 목표

### 1.1 한 줄 요약
> 현대에서 말과 글자가 사라져간다. 그 원인은 과거에 있다.
> 주인공은 타임머신을 타고 조선으로 건너가, 마물을 몰아내고 **세종의 한글 창제를 조력**한다.

### 1.2 인과 구조 (시간여행 논리)
1. **현대**: 사람들의 말이 소리로 나오지 않고, 간판·책·화면의 글자가 부서져 사라진다.
2. **원인**: 누군가 과거에서 **한글 창제 자체를 지우고 있다**. 한글이 태어나지 않으면 현대의 한글은 존재하지 않는다.
3. **주인공**: 현대인. 증거물로 **훈민정음 해례본(현대의 영인본)**을 품고 타임머신에 탑승, 1443년 조선으로 간다.
4. **조선**: **묵음 대왕(默音大王)**과 그 마물들이 자모를 흩고 세종의 창제를 방해하고 있다.
5. **목표**: 마물 제거 → 흩어진 자음 회수 → **세종에게 전달해 창제를 완성** → 현대의 말과 글자가 돌아온다.

### 1.3 최종 보스: 묵음 대왕
- 이름의 이중 의미: **默(침묵) + 墨(먹)** — "소리 없음"이자 "먹으로 지움". 살아있는 먹물로 이루어진 도깨비 왕.
- 목적: 세상에서 **소리와 글자의 대응**을 지우는 것. 그래서 창제를 막는다.
- 외국인 관점: **"The Silent King"** — silent letter(묵음)는 영어권에도 있는 개념이라 번역 시 설명이 필요 없다.
- 기존 키아트(`ArtDrop/boss_ganada.png`, 먹물 도깨비 왕)는 **컨셉 그대로 재사용 가능** — 이름/파일명만 교체.

### 1.4 훈민정음 파편의 정체 (v2 재정의)
- 시간 도약의 충격(+묵음 대왕의 간섭)으로 주인공이 들고 온 **해례본이 찢겨 조선 각지로 흩날린다** (오프닝 컷3).
- 즉 파편 = **미래에서 온 완성본의 조각**. 이것이 세종을 조력할 근거가 되고, 다 모이면 창제가 완성된다.
- 창제가 완성되어야 미래에 해례본이 존재하고, 그 해례본을 주인공이 들고 왔다 — 의도된 **시간 순환 구조**. 엔딩의 서문 낭독이 이 고리를 닫는다.
- 창제 전 시대에 "훈민정음 복원"이라는 표현이 성립하는 이유가 이 설정으로 해소된다 (v1의 논리 구멍 수정).

## 2. 오프닝 4컷 (아트 트랙과 1:1 대응)

별도 트랙에서 제작되는 4컷 일러스트의 **내용 확정본**. 컷 번호 = 아트 파일 번호.

| 컷 | 제목 | 내용 | 필수 요소 (아트) |
|---|---|---|---|
| 1 | 현대의 혼란 | 도시의 간판·전광판·책의 글자가 ▒로 부서져 흩어진다. 사람들이 입을 열지만 말풍선이 비어 있다. | 깨진 글자 ▒ 표현, 빈 말풍선, 현대복 주인공(뒷모습/군중 속) |
| 2 | 타임머신 | 주인공이 **해례본을 품에 안고** 타임머신에 탑승. 계기판의 글자마저 깨져간다. | 해례본(품에 안음), 현대복 전신 첫 노출, 1443 표기 |
| 3 | 조선 도착 | 숲에 불시착. 충격으로 **해례본이 찢겨 빛나는 파편이 사방으로 날아간다**. 타임머신은 부서져 있다(귀환 불가 = 동기). | 흩날리는 파편, 부서진 타임머신, 현대복 주인공, 시작의 숲 톤(연녹·아침 안개) |
| 4 | 세종 만남 | 잠행(미복 시찰) 중인 세종과 조우. 세종이 주인공의 **옷**을 보고 있다. | 세종(미복 차림), 현대복 주인공, 시선이 옷에 가 있는 구도 |

### 3.1 배치
- 장소: **시작의 숲(map_01) 초입** — `사이드뷰 전환 기획` 7.1장 ①구간(x0~20 완전 평지)과 겹친다.
- 흐름: 컷1~4 재생 → **x=0 현대복으로 조작 시작** → x≈4에서 세종과 조우(3.2 대화) → **한복 전환** → x=6 스팟 61부터 기존 튜토리얼.

## 4. 깨진 글자 시스템 (v1 유지 — 새 세계관에서 의미가 강화됨)

- 아직 세상에 없는 자음이 포함된 글자는 **깨진 형태(▒)**로 표시된다 (물음표가 아니라 균열/먹 번짐/글리치).
- **v2에서의 의미**: v1에서는 "대마왕이 빼앗아 간 글자"였지만, v2에서는 **"아직 창제되지 않았거나 묵음 대왕이 지운 글자"**다.
  현대의 소멸(컷1)과 조선의 ▒가 **같은 현상의 양끝**이라는 점에서 연출 논리가 더 단단해졌다.
- 판정 규칙: 글자의 **초성·종성에 미회수 자음이 하나라도 있으면 깨짐. 모음은 항상 온전**. (D-23 BrokenText 구현과 일치)
- 적용 범위: 타이틀, 맵 이름, 출구 표지, 상점 간판, 방 이름, UI 텍스트 일부.
  - 타이틀 "한글 어드벤처"는 최초 실행 시 온전 → 오프닝 후 ㅎ·ㅇ·ㅊ·ㅂ 미회수 상태이므로 "▒글 ▒드▒▒"로 깨진다.
  - 최고의 연출 무대는 **낱말 저잣거리의 간판들**(아트 디렉션 4-5). 자음을 되찾을수록 장터가 글자를 되찾는다.
- 시각 표현 방식(셰이더 vs 대체 글리프 vs 오버레이)은 여전히 미결 (11장).

## 5. 경복궁 — 세종 NPC 퀘스트 허브 (v2 신규 역할)

**경복궁은 최종 스테이지가 아니다.** 최종 결전은 묵음 대왕의 영역에서 벌어지고, 경복궁은 **거점**이다.

### 5.1 역할
1. **자음 등재소**: 회수한 자음을 세종에게 바치면 세종이 그것을 **훈민정음에 새긴다**. 자음 회수 팝업(D-23) 이후의 "정산" 장소.
   - 등재할 때마다 경복궁 안뜰의 **창제 진척판(자모 배열도)**이 한 칸씩 채워진다 → "창제를 조력한다"가 눈에 보이는 지표가 된다.
2. **세종의 의뢰 (반복 퀘스트)**: 세종이 특정 글자·단어 제작을 의뢰한다.
   - v1 4.5장의 "NPC 심부름 퀘스트"를 **세종 본인의 의뢰로 격상**한 것. 데이터는 스테이지와 동일하게 JSON.
   - 예: "**'백성'**이라는 낱말을 지어 오너라", "받침이 있는 글자를 셋 지어 오너라", "ㅁ이 들어간 글자를 다섯 지어 오너라"
   - 보상: 골드 / 훈민정음 파편 / 글자 도감 힌트 / 장비.
   - 반복 가능: 회수한 자음이 늘수록 의뢰 풀이 넓어진다(사용 가능 자모 = 회수 자음). **자연스러운 난도 상승 + 반복 콘텐츠**.
3. **파편 봉납**: 흩어진 해례본 파편을 가져오면 세종이 붙여 나간다. 파편 진행도 = 최종장 개방 조건.
4. **집현전 연결**: 경복궁 내부 구역으로 집현전 배치(초안 13장의 장소 목록 소화). 글자 도감 열람소 겸용.

### 5.2 구현 시점
- **MVP 범위 밖.** MVP는 기존대로 시작의 마을(map_02)이 허브다.
- 경복궁은 **신규 맵으로 추가**(map_06 제안)하고, 마을에서 이어지는 출구에 게이트를 건다.
- MVP에서는 세종을 **마을의 임시 NPC 1명**으로 두고 "등재" 기능만 붙여도 루프가 성립한다 (경복궁 미구현 시 폴백).

## 6. 자음 회수·게이트·파편

### 6.1 자음 회수 (D-23과 일치, 재확인)
- 시작 보유: **ㄱ, ㄴ, ㄷ** (세종이 이미 만들어 남은 것 — `pro_07`).
- 회수 11개, 한글 자음 순서: 숲 완주→ㄹ / 마을 방A→ㅁ / 마을 방B→ㅂ / 고개 방→ㅅ / **고개 보스→ㅇ** / 사찰 방1→ㅈ / 사찰 방2→ㅊ / **사찰 보스→ㅋ** / 저잣 방1→ㅌ / 저잣 방2→ㅍ / **저잣 보스→ㅎ(최종)**.
- 회수 = "마물에게서 빼앗은 글자" → 경복궁에서 세종에게 등재(5.1) → 세상의 ▒가 그 자음만큼 복원.

### 6.2 게이트 (v2 확정 — "출처 힌트" 폐기)
- 지역·방 진입 차단은 **자음 회수 진행도 게이트**로 통일한다 (D-22 + 맵 출구 `required`).
- 스토리상의 이유: **문패에 적힌 글자를 읽을 수 있어야 그 문을 지난다.** 미회수 자음이 든 문패는 ▒라서 읽을 수 없다 = 통과 불가.
  - 규칙이 스토리와 완전히 일치하고, 외국인에게도 설명이 필요 없다("읽을 수 없으면 못 간다").
- 현행 수치 유지: 마을 required 0 / 받침 고개 3 / 자모 사찰 5 / 낱말 저잣거리 8.
- 잠긴 문 앞 UI는 **"필요한 자음" 힌트**를 보여준다 (D-22). 이미 별을 딴 스테이지는 재게이트하지 않는다.

### 6.3 훈민정음 파편
- 획득 경로 (복수 채널, v1 유지):
  1. 방 여러 개 클리어 보상
  2. 맵 탐험: 특정 위치 도달/행동 시 발견 (숨겨진 보물)
  3. **맵 자체가 거대한 퍼즐**: 단계 클리어 → 맵 요소 변형 → 맵 퍼즐 해결 시 파편 (MVP 이후)
  4. 상점에서 고가 판매
  5. **세종의 의뢰 보상** (v2 신규, 5.1)
- **정합성 제약(유지)**: 파편 완성 시점 = 자음 전부 회수 상태. 마지막 파편은 최종 지역(마지막 자음 지역)에 배치.
- 엔딩: 파편 완성 → 세종이 해례본을 완성 → **묵음 대왕과 최종 결전**.

## 7. 사천왕 구조 (v1 유지 — 새 세계관에 재배치)

### 7.1 재배치
- 묵음 대왕의 부하 **사천왕** 4명이 각 지역의 주인이자 최종 시험 (포켓몬 관장 모델).
- **v2 재해석**: 사천왕은 원래 **그 지역의 장인·승려·상인이었으나 묵음에 물든 자들**이다.
  - 격파 = 처치가 아니라 **정화**. 정화된 사천왕은 제정신을 찾고 **세종의 조력자로 전향**해 경복궁 의뢰에 이름을 올린다.
  - 이 재해석의 이득: (a) "마물 제거 + 창제 조력"이라는 목적과 톤이 맞고, (b) **사천왕 재대결**이 "복수전"이 아니라 **"스승과의 수련"**이 되어 엔드게임 콘텐츠로 자연스럽다.

| # | 이름 | 지역 | 테마 | 보상 자음 |
|---|---|---|---|---|
| 1 | 받침 사범 | 받침 고개 (map_03) | 받침 글자 | ㅇ |
| 2 | 겹자모 노승 | 자모 사찰 (map_04) | 이중모음·겹자모 | ㅋ |
| 3 | 낱말 장사꾼 | 낱말 저잣거리 (map_05) | 두 글자 단어 | ㅎ |
| 4 | 미궁의 넷째 | 왜곡된 문자 미궁 (미구현) | 미정 — 가장 강하고 미스터리 | 미정 |

- 격파 보상: 자음 회수 + **증표(배지)** 진열 + 파편 경로 연결.
- **4번째 사천왕의 지역이 MVP 범위 밖**이라 현재 배치처가 없다 → 11장 미결.

### 7.2 모험 요소 4종 (v1 확정분 유지)
1. **글자 도감**: 만든 모든 글자가 자동 기록. 최초 합성 시 등록 연출, 달성률, 희귀 글자(겹받침·복합모음) 특별 표시. 우선순위 최상.
2. **NPC 심부름 퀘스트**: v2에서 **세종의 의뢰**로 격상(5.1) + 지역 NPC 의뢰는 그대로 유지.
3. **숨겨진 보물**: 맵 구석·수풀 뒤 상호작용으로 발견(골드/파편/장비). "맵이 거대한 퍼즐"의 최경량 형태.
4. **사천왕 재대결**: 정화된 사천왕과의 **수련 대련**(더 어려운 퍼즐/짧은 제한 수). 상위 증표·도전과제. 엔드게임.

## 8. 전투 시스템 (v1 유지, 변경 여지 있음)

- 행동: **공격 / 수비 / 기술**. 대미지 = (공격력 또는 기술 공격력) − (상대 방어력). 수비 = 다음 피해 경감.
- **몬스터의 반격 구조**: 내가 행동하면 몬스터가 간단한 한글 퍼즐을 제시.
  - 제한 이동 수 안에 못 풀면 몬스터 공격이 강해지거나 잦아짐 / 제한 내 성공 시 **카운터 펀치**.
- 장비(무기=공격력, 방어구=방어력)가 실수치로 작동 — 상점/골드 루프의 사용처.
- **전조 시스템**: 다음 퍼즐 공격의 난도·제한 수·속성을 미리 표시 → 수비를 전략적으로 선택. 수비 = 다음 퍼즐에 유리한 변형(예: 제한 수 +2).

## 9. 최종 결전: 묵음 대왕

- 장소: **경복궁이 아니다.** 묵음 대왕의 영역(먹에 잠긴 무자(無字)의 땅 — 가칭)에서 벌어진다.
- 개방 조건: 자음 14개 전부 + 파편 전부 → 세종이 해례본을 완성한 직후.
- 보스 기믹(v1 계승): 묵음 대왕의 공격 = **보드의 타일을 깨뜨리거나 지운다**(글자를 지우는 존재의 능력을 그대로 규칙화).
  - **회수한 자음이 많을수록 대응 수단이 많다** → 스토리 진행이 곧 전투력. 수집이 서사와 시스템 양쪽에서 보상된다.
- v2 추가 연출 제안: 최종전 중 세종이 **원군이 아니라 후방에서 글자를 새겨 보내준다** — 깨진 타일이 세종의 붓질로 복구되는 형태.
- **패배 조건 톤**: 주인공이 죽는 게 아니라 **말을 잃는다**(현대의 증상이 완성된다). 게임오버 화면이 서서히 ▒로 덮인다.

## 10. 엔딩

1. 해례본 완성 → 묵음 대왕 격파 → 조선의 모든 ▒가 글자로 돌아온다(맵 전역 복원 연출).
2. **훈민정음 서문**이 등장한다.
   > 나랏말ᄊᆞ미 듕귁에 달아 / 문자와로 서르 ᄉᆞᄆᆞᆺ디 아니ᄒᆞᆯᄊᆡ…
   - 원문 + 현대어 + 영어 해석을 함께 노출 (초안 16장).
3. **v2 신규 엔딩 비트**: 주인공이 현대로 돌아온다. 간판이, 책이, 사람들의 말이 전부 제자리에 있다.
   - 마지막 컷: 주인공이 **처음으로 소리 내어 말한다**. 오프닝 컷1의 빈 말풍선이 글자로 채워지는 대구(對句).
   - 시간 순환의 고리 닫기: 주인공이 들고 갔던 그 해례본이 박물관 유리장 안에 온전히 놓여 있다.
